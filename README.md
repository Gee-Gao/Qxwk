# 千薪万苦（Qxwk）

把月薪换算成每一秒，实时看见自己正在赚多少钱。

「千薪万苦」是一个纯前端、可离线安装的 PWA 小应用：输入月薪和上下班时间后，它会用倒计时的方式实时展示今天已经赚了多少钱、距离下班还有多久，并把加班、记账、调休、通勤、设备成本等一并折算成「生命时长」和「工资」。

> 数据全部保存在浏览器本地（localStorage），不上传任何服务器。

## 在线访问

直接打开：<https://gaoyunqiang.netlify.app/>

- 手机浏览器打开后可「添加到主屏幕」，像 App 一样使用
- 首次打开会停在设置页，填好月薪和上下班时间即可
- 安装后支持离线打开，断网也能看计时

## 功能

### 计时
- 实时显示「今日已赚 / 本月已赚」与对应时薪
- 距离下班的倒计时、当日工作进度条
- 支持午休时段扣除、试用期薪资折算，并标注当前处于试用期还是正式期
- 支持跨天夜班（如 22:00–06:00），凌晨时段自动归入前一天开始的班次
- 工资口径可选：税前 / 税后 / 税前税后对比
- 可选叠加外币换算金额（USD、HKD、EUR、GBP、JPY、KRW、SGD、AUD、CAD、TWD、CHF、THB 共 12 种）
- 通勤可计入时薪与收益：
  - 支持「一天合计」或「往返分开」两种填法
  - 通勤单独计时，不影响上下班主倒计时与进度条
  - 去程显示「距离到岗」、返程显示「距离到家」，状态标注「通勤中」
  - 顶部徽章展示当天含通勤的总时长
- 今日格言与加班费小面板
- 一键生成今日战绩分享图：薪资、倒计时、通勤、加班、记账、生命消耗、年度概览均可勾选，支持税前/税后与外币换算（Canvas 本地绘制）

### 加班
- 按小时或按天记录加班，倍率支持 1.5 / 2 / 3 / 自定义
- 按天录入时，按每日实际工作时长（已扣除午休）折算金额
- 加班结算方式：给钱或调休；调休可记录使用时长并自动抵扣结余（剩余 = 加班 − 已调休）
- 加班金额可选择是否计入计时页，加班费卡片可设为始终展示 / 有则展示 / 始终隐藏
- 记录列表支持删除，调休模式下可只看加班或只看调休

### 记账
- 按月日历切换日期查看当天记录，上方「记一笔」按钮进行记账
- 点击记录可修改金额、项目或备注，记录右侧 × 可删除
- 内置餐饮、交通、水费、电费、燃气、取暖、租房、礼金、购物、娱乐、医疗、保险、通讯、学习、其他 15 类常用项目
- 支持自定义项目名称与图标，自定义项目可删除
- 金额实时折算工作日（1 天 = 一个工作日的收入），单位按 秒 → 分钟 → 小时 → 工作日 逐步递增
- 图表 Tab：支持「月度统计 / 年度统计」切换，年度为累计口径（1 月统计 1 月，2 月统计 1-2 月，依次累计）；包含支出与折算工作日、工资与剩余工资、日均支出、记账天数、分类占比、支出趋势、之最

### 统计
- 「看一看」：
  - 生命消耗大盘：入职天数、打工天数、折合生命、已换工资（含历史工作）
  - 本月扣缴明细：应发工资、社保个人、公积金个人、当月个税、累计已缴个税、实发工资
  - 本月概览：已赚、进度、消费三条进度条
  - 时薪波动曲线：最近 12 个月（不早于最早一段工作经历）的当月平均时薪折线，按月薪 ÷ 每日计时工时 ÷ 当月工作日数计算，同月跨两段工作按工作日加权，空档月显示为 0，并标出比上一段多赚 / 少赚多少
  - 年度工资轨迹：已赚、进度、剩余预计、年度消费
- 「算一算」：
  - 带薪离席计时：离开工位的时间也在赚钱，结束后自动结算
  - 反向计算器：摸鱼能白拿多少 / 赚到目标要熬多久
  - 设备使用成本：按购买时间折算每小时成本，最多 10 台设备

### 历史工作
- 跳槽时可在「设置 → 历史工作」一键归档当前工作，当前工作会顺延到次日，等待填写新工作参数
- 也可在设置页「历史工作」卡片点击「＋ 添加历史工作」，通过弹窗录入，字段与当前工作一致，并额外填写离职日期（月薪、入职 / 离职、试用期、上下班时间、休息制度、通勤与税后测算参数）
- 生命消耗大盘、时薪波动曲线、月度 / 年度收入与加班费都会按每段工作的任职时间分段计算，历史工作不会和当前工作重复计数
- 历史工作支持编辑、删除，保存后自动纳入统计

### 设置
- 休息制度：双休 / 单休 / 大小周 / 自定义日历
  - 自定义模式下可按日历逐日勾选上班日，每月工作天数自动计算
  - 每月首次进入会提示选择当月工作日（当月取消后不再重复弹出）
- 已工作天数小数位（0 / 1 / 2 位）
- 工资口径：税前 / 税后 / 税前税后对比
- 当前工作支持填写公司名称，归档时自动作为历史工作名称
- 税前月薪、入职日期、试用期月数与试用期薪资比例，转正日期自动计算
- 上下班时间与午休时间（夜班时对应为休息时段）
- 税后测算：
  - 社保、公积金缴费基数（留空按税前月薪）
  - 养老、医疗、失业、住房公积金个人比例
  - 大额医疗互助固定金额（部分城市如北京每月 3 元）
  - 子女教育、婴幼儿照护、继续教育、住房贷款利息、住房租金、赡养老人六项专项附加扣除
  - 按累计预扣法逐月估算个税，入职当月工资按 21.75 天折算
- 法定节假日与调休补班自动识别（联网获取，失败时使用内置数据兜底）
- 数据备份：导出全部业务数据为 JSON（不含可自动获取的汇率、节假日缓存），或导入备份文件恢复（导入会覆盖现有数据）

## 技术说明

- 纯静态应用：HTML 结构、CSS 样式与 JavaScript 逻辑分别放在 `index.html`、`css/index.css`、`js/index.js` 中，无构建步骤、无第三方运行时依赖
- 日期与时间使用自绘选择器，不依赖浏览器原生控件，各端表现一致
- PWA：通过 `manifest.json` 与 `sw.js` 支持安装到桌面/主屏及离线访问
- 存储：`localStorage`
- 外部接口（均为可选，失败时有本地兜底）：
  - 汇率：`https://open.er-api.com/v6/latest/CNY`（缓存于 `qianxwk_fx_rates`）
  - 节假日：`https://timor.tech/api/holiday/year/`（按年缓存 30 天）

## 本地运行

由于 Service Worker 只能在 `http(s)` 或 `localhost` 下注册，直接双击打开 `index.html` 时 PWA 与离线能力不会生效，但页面功能仍可正常使用。

推荐用任意静态服务器启动：

```powershell
# 方式一：Python
python -m http.server 8080

# 方式二：Node.js
npx serve .
```

然后访问 <http://localhost:8080>。

## 常见问题

**1. 为什么和工资条有差异？**
这里做的是估算：社保公积金基数可能有上下限，个税未考虑年终奖、劳务报酬等特殊计税，专项附加扣除也按你填写的固定值计算。用于日常参考，不替代工资条。

**2. 换手机后数据怎么办？**
在旧设备「设置 → 数据备份」导出 JSON，在新设备导入即可（导入会覆盖现有数据）。

**3. 为什么直接双击 HTML 打不开离线功能？**
Service Worker 需要 `http(s)` 或 `localhost` 环境，用上面的静态服务器方式启动即可。

**4. 需要联网吗？**
核心功能完全离线可用；汇率与节假日为可选增强，联网失败时会使用内置数据或上次缓存。
