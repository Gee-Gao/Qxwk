# 千薪万苦（Qxwk）

把月薪换算成每一秒，实时看见自己正在赚多少钱。

「千薪万苦」是一个纯前端、可离线安装的 PWA 小应用：输入月薪和上下班时间后，它会用倒计时的方式实时展示今天已经赚了多少钱、距离下班还有多久，并把加班、消费、调休、设备成本等一并折算成「生命时长」和「工资」。

> 数据全部保存在浏览器本地（localStorage），不上传任何服务器。

## 功能

### 计时（首页）
- 实时显示「今日已赚 / 本月已赚」与对应时薪
- 距离下班的倒计时、当日工作进度条
- 支持午休时段扣除、试用期薪资折算
- 工资口径可选：税前 / 税后 / 税前税后对比
- 可选叠加外币换算金额（如 USD、EUR、JPY 等 12 种）
- 今日格言与加班费小面板

### 加班
- 按小时或按天记录加班，倍率支持 1.5 / 2 / 3 / 自定义
- 加班结算方式：给钱或调休；调休可记录使用时长并自动抵扣结余
- 加班金额可选择是否计入计时页，加班费卡片可设为始终展示 / 有则展示 / 始终隐藏

### 统计
- 「看一看」：生命消耗大盘、本月概览、年度工资轨迹
- 「算一算」：
  - 带薪离席计时（离开工位的时间也在赚钱）
  - 反向计算器：摸鱼能白拿多少 / 赚到目标要熬多久
  - 设备使用成本：按购买时间折算每小时成本，最多 10 台设备

### 消费
- 把消费价格换算成「需要上多久班才能买得起」
- 内置常用消费项目，可自定义名称、价格与 emoji 图标，支持编辑和删除

### 设置
- 休息制度：双休 / 单休 / 大小周 / 自定义日历
  - 自定义模式下可按日历逐日勾选上班日，每月工作天数自动计算
  - 每月首次进入会提示选择当月工作日（当月取消后不再重复弹出）
- 已工作天数小数位（0 / 1 / 2 位）
- 税前月薪、入职日期、试用期月数与试用期薪资比例
- 上下班时间与午休时间
- 税后测算：社保 / 公积金基数与个人比例、六项专项附加扣除，自动按累计预扣法估算个税
- 法定节假日与调休补班自动识别（联网获取，失败时使用内置数据兜底）

## 技术说明

- 单文件应用：全部 HTML / CSS / JavaScript 都内联在 `index.html` 中，无构建步骤、无第三方运行时依赖
- PWA：通过 `manifest.json` 与 `sw.js` 支持安装到桌面/主屏及离线访问
- 存储：`localStorage`
- 外部接口（均为可选，失败时有本地兜底）：
  - 汇率：`https://open.er-api.com/v6/latest/CNY`（缓存于 `qianxwk_fx_rates`）
  - 节假日：`https://timor.tech/api/holiday/year/`（按年缓存 30 天）

## 本地运行

由于 Service Worker 只能在 `http(s)` 或 `localhost` 下注册，直接双击打开 `index.html` 时 PWA 与离线能力不会生效，但页面功能仍可正常使用。

推荐用任意静态服务器启动：

```powershell
# 方式一：Python
python -m http.server 8080

# 方式二：Node.js
npx serve .
```

然后访问 <http://localhost:8080>。

## 部署

项目是纯静态资源，可直接部署到任意静态托管服务（GitHub Pages、Netlify、Vercel、Cloudflare Pages、Nginx 等），无需额外配置。若使用子路径部署，`manifest.json` 与 `sw.js` 中的相对路径（`./`）可正常工作。

## 项目结构

```
Qxwk/
├── index.html        # 应用主体（结构、样式、逻辑全部内联）
├── manifest.json     # PWA 清单
├── sw.js             # Service Worker：预缓存应用外壳、离线回退
├── icons/            # 应用图标（192 / 512 / maskable / apple-touch）
├── LICENSE           # MIT 许可证
└── README.md
```

## 本地数据

| 键名 | 内容 |
| --- | --- |
| `qianxwk_settings` | 全部设置项 |
| `qianxwk_items` | 消费项目 |
| `qianxwk_devices` | 设备成本列表 |
| `qianxwk_leave` | 带薪离席计时记录 |
| `qianxwk_overtime` | 加班记录 |
| `qianxwk_leave_used` | 调休使用记录 |
| `qianxwk_fx_rates` | 汇率缓存 |
| `qianxwk_holiday_<年份>` | 节假日缓存 |

清除浏览器站点数据会同时清空以上全部内容。

## 浏览器支持

面向现代浏览器（Chrome / Edge / Safari / Firefox 及移动端内核）。使用了 `dvh`、`color-scheme` 等较新特性，建议保持浏览器为较新版本。
